# ribbit
Social network. Redefined.

# Serve the server

1. First install [just](https://github.com/casey/just?tab=readme-ov-file#installation)
2. Install the tailwindcss [standalone cli](https://tailwindcss.com/blog/standalone-cli)
3. Run `just serve` to start the server
4. Open https://127.0.0.1/fr/

It will compile tailwindcss and launch the docker.
